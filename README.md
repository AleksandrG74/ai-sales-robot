**AI Sales Robot** — это интеллектуальный цифровой продавец для малого бизнеса и интернет-магазинов. В отличие от классических скриптовых ботов, система использует **Transfer Learning без переобучения LLM**, адаптируясь к стилю общения и словам клиентов, которые реально ведут к покупке (на основе анализа PMI и весов слов).

## 🏗 Архитектура

Проект построен на микросервисной архитектуре и разворачивается через `docker-compose`. Взаимодействие с внешним миром обеспечивает reverse-proxy **Nginx**.

| Сервис | Назначение |
| :--- | :--- |
| 🔍 **`miner`** | Анализ диалогов, извлечение паттернов (PMI, веса слов), самообучение. |
| 🧠 **`dialogue`** | Генерация ответов LLM с учётом накопленного опыта и стратегий. |
| 💬 **`live`** | Обработка живых чатов, Long Polling, подготовка рекомендаций для оператора. |
| ✈️ **`telegram`** | Интеграция с Telegram (клиенты, мониторинг каналов, сессии). |
| 🌐 **`web`** | FastAPI-бэкенд: CRM, дашборд, демо-страница, API, Basic Auth. |
| 🛡 **`nginx`** | Reverse-proxy, SSL-терминация, маршрутизация статики и API. |

## ✨ Ключевые фичи

- 🧬 **Адаптация без переобучения LLM** — базовая модель остаётся неизменной, система учится на словаре успешных переходов (PMI), что экономит бюджеты на GPU.
- 🔄 **Long Polling** — используется вместо `events.NewMessage` для стабильной работы даже при ограничениях Telegram.
- 🛑 **Безопасный режим (`LIVE_AUTO_REPLY=0`)** — робот не спамит в чат, а генерирует **подсказки для оператора** (Human-in-the-loop).
- 🐈‍⬛ **Робот Салем** — живой демо-чат на сайте, где можно проверить систему в деле.
- 🔐 **Basic Auth** — защита CRM-интерфейса из коробки.

## 🚀 Запуск локально (Docker)

Для запуска проекта на вашей машине потребуется установленный **Docker** и **Docker Compose**.

```bash
# 1. Клонируйте репозиторий
git clone <your-repo-url> ai-sales-robot
cd ai-sales-robot

# 2. Создайте файл .env на основе примера и заполните ключи (LLM API, Telegram и т.д.)
cp .env.example .env
nano .env

# 3. Запустите контейнеры в фоновом режиме
docker compose up -d

# 4. Проверьте статус
docker compose ps
После запуска CRM будет доступна по адресу http://localhost:8080 (внутренний порт Docker-контейнера).

Для работы через домен salemind.ru требуется настроенный Nginx (он конфигурируется на самом сервере отдельно и не входит в базовый docker-compose для локальной разработки).
