# Маппинг алгоритмов диалога на 5 этапов сделки

Анализ 96 тредов (bootstrap) выявил 14 алгоритмов диалога. 
Все они отображаются на 5 универсальных групп (этапов сделки):

| Реальный алгоритм | Этап сделки | Обоснование |
|---|---|---|
| Инфоповод (новость, обычное) | greeting | Начало диалога |
| Вопрос | curiosity | Интерес |
| Обсуждение | curiosity | Развёрнутый интерес |
| Утверждение | curiosity/objection | Контекстно |
| Оскорбление | objection | Скепсис |
| Возражение | objection | Прямое возражение |
| Не-согласие / эскалация | objection | Конфликт |
| Эмоциональное (да) | agreement | Согласие |
| Повседневное (ок) | agreement | Фиксация |
| Деловое (согласен) | agreement | Деловое согласие |
| Сленг (база) | agreement | Усиление |
| Переход в быт | closing | Закрытие микротемы |
| Закрытие | closing | Финал сделки |

**Вывод:** 5 групп — не хардкод продаж, а **универсальная онтология**. 
Любой диалог (треп, футбол, IT) отображается на эти 5 этапов.
